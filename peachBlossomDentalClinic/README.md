# Dental Clinic Management System

A full-stack web application designed to streamline dental clinic operations by managing patients, appointments, doctors, invoices, payments, and administrative workflows.

## Features

### Admin Features
* Secure Admin Authentication
* Patient Management (Add, Edit, Delete)
* Doctor Management
* Appointment Scheduling
* Invoice Generation
* Payment Tracking
* Dashboard Overview

### Patient Features
* Account Activation via Email
* Secure Password Setup
* Login & Authentication
* Appointment Booking
* View Invoices and Payments
* Contact Clinic Through Messaging System


### Additional Features
* Modern JavaScript (ES6 Modules)
* Email Notifications with Nodemailer
* Password Hashing using bcrypt
* MongoDB Data Modeling
* Server-Side Rendering with EJS
* Responsive User Interface


## Tech Stack

### Backend
* Node.js

## Installation

1. Clone the repository

```bash
git clone https://github.com/ShanuKohinoor/DentalClinicProject.git
```

2. Navigate to the project folder

```bash
cd DentalClinicProject
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and configure the required environment variables.

5. Start the application

```bash
npm start
```
